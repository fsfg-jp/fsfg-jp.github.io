# 初代星・初代銀河研究会アーカイブ

初代星・初代銀河研究会の過去のWebページと発表資料を維持するためのリポジトリです。

- 公開サイト: https://fsfg-jp.github.io/
- GitHub Organization: https://github.com/fsfg-jp
- リポジトリ: `fsfg-jp/fsfg-jp.github.io`

## 公開構成

- GitHub Pages: HTMLページと小さな画像
- GitHub Releases: `2019` Releaseの個別発表資料52件
- 非公開: `2019/pdf/all.tar.gz`と未掲載の手元資料

`all.tar.gz`は個別資料と重複するため、GitHubにはアップロードしません。手元の原本はバックアップとして保持します。

## 運用方針

- OrganizationのOwnerは2名以上にする
- ページの修正はPull Request経由で行う
- 発表資料は年ごとのReleaseで管理する
- 移管時に利用した原本は、GitHubと別の場所にもバックアップする
